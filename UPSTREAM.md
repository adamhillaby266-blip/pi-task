# Upstream provenance

Pi Task uses Pi Web as its clean, licensed engineering baseline.

- Upstream project: <https://github.com/agegr/pi-web>
- Imported release: `v0.8.6`
- Imported commit: `dfab5853b8d2f717df259e7ebc94f49a3c2e43e7`
- Import commit in this repository: `99b1b00a7c9efd74ff0581c17820d052739cb9e5`
- Upstream license: MIT
- Copyright notice: retained in [`LICENSE`](./LICENSE)

The initial import excludes the upstream Git history but preserves the exact tracked source snapshot in the first commit. Product changes are implemented in later commits so the baseline remains auditable.

The dashi-taskboard research repository was not used as a source-code baseline because no public license was found during review. Pi Task only adopts independently described workflow concepts and does not copy its source, pages, screenshots, or assets.
