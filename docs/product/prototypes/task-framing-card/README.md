# 任务约定卡交互原型

该原型用于验证 Task Framing 的对话内信息层级和状态，不接入 Pi SDK、SQLite 或任何模型。

2026-08-14 人工检查已确认：视觉回到 Pi Web / Pi Task 既有体系，主对话可以顺畅纵向滚动，底部“确认并放入待办”“确认并开始”等操作完整可达。当前版本作为后续实现的视觉与交互基线。

## 查看

在本目录启动静态文件服务：

```bash
python3 -m http.server 31432 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:31432/
```

## 建议体验路径

1. 阅读自由对话中的低压力任务化建议。
2. 点击“与已确认预算比较”和“不含物流”，观察草案进入待确认状态。
3. 点击“确认并放入待办”，确认不会自动开始。
4. 点击“现在开始”，观察显式 Run 起点。
5. 使用顶部状态栏检查保存失败、启动失败和已放弃状态。
6. 在输入框用自然语言补充决定，观察旧草案折叠和新草案更新。
7. 缩窄浏览器检查移动端信息顺序与按钮布局。

## 数据与边界

- 全部项目、财年、文件和任务编号均为虚构。
- 原型不发送网络请求，不读取项目资料，不写入 Task 数据。
- 原型中的视觉语言作为实现基线，但静态数据、状态切换器和模拟行为不代表技术实现。
